사용자명 저장소 파일 경로 토큰
토큰 만드는 방법 (최초 1회)
  1. GitHub 로그인 → 우상단 프로필 → Settings
  2. 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access: Only select repositories → 이 저장소만 선택
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate 후 표시되는 토큰을 복사해 위에 붙여넣기 (토큰은 절대 저장소에 올리지 마세요)

기록 커버리지 (월별 기록일수)

달마다 일지가 기록된 날의 수 — 연도 중앙값의 70% 미만인 달(빈 원)은 추이 해석에 주의

연도 × 공정 부하 히트맵 (월평균 M·H)

각 연도의 기록월수로 정규화한 월평균 M·H · Δ는 전년 대비 증감률 · ⚠ 2023년은 공정 표기 체계가 달라(구체계 40여 종) 연도 간 직접 비교에 주의, 2026년은 부분 기록
